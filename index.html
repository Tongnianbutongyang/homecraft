关于工作室

欢迎来到 老猪工作室 / Oldpig Studio。这是一座软陶色的方块小岛：西边是展厅，东边是 OMC 控制台，北边是 API 灯塔，东南是 LunaTV 影音馆，南草坪有 OpenMausBot 助手亭。走近建筑按 F，或点 Dock 打开卡片。

工作室入口与工具请走 OMC / 工作室入口（www.oldpig91.com）；影视看 LunaTV，助手走 OpenMausBot。这里只做访客友好的入口，不展示密钥或代理入口。
